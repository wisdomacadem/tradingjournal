# 📈 Trading Journal Pro

A professional trading journal and performance analytics application built with HTML, CSS, and JavaScript.

This project helps traders track trades, analyze performance, measure risk management, and improve consistency through detailed statistics and reporting.

---

## 🚀 Live Demo

https://wisdomacadem.github.io/tradingjournal/

---

## 📖 Overview

Trading success is not only about finding entries and exits.

Professional traders keep detailed records of every trade so they can:

- Identify strengths and weaknesses
- Improve risk management
- Track performance over time
- Measure consistency
- Build profitable habits

This application simulates a professional trading journal used by active traders.
